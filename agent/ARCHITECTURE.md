# Lore · Agent 架构

一条日记从说话到成页，经过下面这些节点。原则：**能用代码做的不调模型；必须调模型的用最便宜、实测过的模型；模型的输出一律由代码校验，校验不过就退回不调 API 的规则版。**

```
录音 ──► ① 转写 ──► ② 修口吃（每段录音一次） ──► 原话文本（排版前只显示这个）
照片 ─────────────────────────────────────────┐
                    用户点「排版」 ──► ③ 照片对号（代码） ──► ④ 排版
                                                         ├─ 免费：纯代码（文字绕图的流式排版）
                                                         └─ 付费：⑤ 版面导演（模型给版式，代码校验后排）
```

## 节点

| 节点 | 免费 | 付费 | 做法 | 文件 |
|---|---|---|---|---|
| ① 转写 | ✓ | ✓ | OpenAI gpt-transcribe（带中英混说提示），在后端调用 | `worker/src/index.js` |
| ② 修口吃 | ✓ | ✓ | 一次便宜模型调用 + 代码清扫 + 代码校验，失败重试一次，再失败退回规则版 | `clean.mjs` |
| ③ 照片对号 | ✓ | ✓ | 纯代码：识别「一号是…」「三到六号…」「number one is…」「the sixth photo…」 | `match.mjs` |
| ④ 排版 | ✓ | ✓ | 纯代码：App 里的文字绕图引擎（字宽表 + 逐行避让），不调 API | `mobile/src/Doc.tsx` |
| ⑤ 版面导演 | | ✓ | 一次结构化调用：标题（只能用原话里的词）、版式、金句（必须原文照抄）、主图、每张图大小；代码校验后交给 ④ 渲染 | `director.mjs` |

付费档以后还可以加：文风学习（导入过去的文字，生成一张「风格卡」放进 ② 的提示词）、语法修正开关（设置里已有）、三天/每周小结、洞察页、「想怎么改这一页」的自然语言改版。都用同一个思路：模型给结构化结果，代码校验，不让模型改用户的原话。

## ② 修口吃：提示词和校验

提示词（`clean.mjs` 里的 `SYSTEM`）只有三段：删什么（口水词、口吃重复、开头说错的半句、改口前的那半句），留什么（其余每个词、方言语气词、kind of 这类软化词、强调用的重复如「绝了绝了」、中英混说一律不翻译、人名数字），以及「只输出整理后的文本」。外加两组示例（一组中英混说，一组英文）。

模型之后，代码依次做：

1. **清扫**：去掉模型漏掉的单独「嗯」「呃」「um」（不碰重复，因为重复可能是强调）。
2. **校验**：英文词丢失超过 25% 或新增英文词、出现原文没有的汉字、删掉大段中文、出现原文没有的数字、加了「此外」「因此」这类书面连接词、比原文还长、带了「以下是…」之类的开场白，都算不通过。
3. 不通过就重试一次；再不通过，这段用**规则版**（代码删口水词和明显重复，不调 API）。

## 选型：实测结果

测试集 `eval/cases.json`：24 段录音（中文、英文、中英混说各 8 段），覆盖口水词、口吃、改口、说错开头、强调重复、方言语气、软化词、人名数字，以及本来就干净、不该被改的句子。每段写明「必须留下」和「必须去掉」的词。每个模型跑两遍，共 48 次。

| 模型（Together AI 按量 / Anthropic） | 通过 | 中位延迟 | 每 1,000 段录音 |
|---|---|---|---|
| **DeepSeek V4 Flash（关闭思考）** | **48/48** | 1.6 秒 | **$0.05** |
| DeepSeek V4.1 Flash（关闭思考） | 48/48 | 0.2 秒 | $0.13 |
| Claude Opus 5.5（质量上限参照） | 48/48 | 1.1 秒 | $3.48 |
| Qwen3.8 Flash（只能流式） | 46/48 | 1.5 秒 | $0.07 |
| Claude Haiku 5.5（关闭思考） | 46/48 | 0.8 秒 | $0.07 |
| Nemotron 3.5 Super（关闭思考） | 46/48 | 0.3 秒 | $0.07 |
| 规则版（不调 API） | 26/48 | 0 | $0 |

第一轮被淘汰的：Qwen3.5-9B 把「周二，不对，周三」改反成了周二（事实错误）；gpt-oss-120b 把 Xiaohongshu 拼错、不处理改口；GLM-5.3 Flash 思考关不掉，长段落一次直接返回空。Llama 3.x、Mistral、Gemma、gpt-oss-20b 等在这个账号上不是按量（serverless）可用的，要单独开专用实例，没测。

**结论**：② 默认用 **DeepSeek V4 Flash**（最便宜、48/48），要更快的界面反馈时换 **V4.1 Flash**（0.2 秒，贵一倍多但仍是每千段 $0.13）。**Claude Haiku 5.5** 做备用（不同厂商，一家出故障时切过去）。

注意：测试段落都很短，表里的成本主要是提示词本身。按一段一分钟的录音（约 350 个 token 进、330 个 token 出）估算，DeepSeek V4 Flash 每段约 $0.0002。

## 转写选型：实测结果

用 Mac 自带的中文和英文语音把那 24 段读出来（合成语音比真人清楚，所以这是排序，不是定论），每个选项都跑完「转写 → 修口吃」整条链路。

| 转写 | 原始错误率 | 英文词保留 | 最终文本通过（24 段，按宽松比对：café = cafe、7 = seven） | 两步合计每分钟 |
|---|---|---|---|---|
| **OpenAI gpt-transcribe** | **2.4%** | **97%** | **21** | **$0.0051** |
| OpenAI gpt-4o-mini-transcribe | 4.7% | 95% | 19 | $0.0036 |
| Together Whisper large-v3 | 6.4% | 95% | 19 | $0.0021 |

gpt-transcribe 剩下的错误大多来自合成语音本身（中文语音把 Lin 读成「林」、把 café 读成 cave），真错的只有一处（recipe 听成 reply）。gpt-4o-mini 会丢英文词（vibe 听成「玩」）；Whisper 会输出繁体、听错字（这事儿 → 这是二，盐 → 延）。所以**上线用 gpt-transcribe**。没能测的：Soniox、ElevenLabs Scribe（没有账号）、Gemini 3.5 Flash-Lite 和 Gemini 3.5 Transcribe（这个账号的预付额度用完了）、Deepgram Nova-3（这个账号不能按量调用）。转写在后端调用，换服务不用改 App。手机自带的转写在 Expo Go 里用不了（需要原生模块），要等 TestFlight 版本。

## 后端（已上线）

Cloudflare Worker：`https://lore-agent.csy2443470971.workers.dev`，代码在 `worker/`。

- `POST /transcribe`：表单字段 `audio`（m4a）→ `{ raw, text, via }`。先 gpt-transcribe，再修口吃：DeepSeek V4 Flash；结果没通过校验就换 Claude Haiku 5.5 再试一次；还不行就用规则版。
- `POST /tidy`：`{ text }` → `{ text, via }`，只修口吃。
- `POST /layout`：`{ text, photos }` → `{ spec }`，付费档的版面导演（Claude Haiku 5.5）。

每个请求都要带 App 的 key（`x-lore-key`），同一个地址每分钟最多 20 次。四个 key（OpenAI、Together、Anthropic、App key）都是 Worker 的 secret，不在 App 里也不在仓库里；App 用到的地址和 App key 放在 `mobile/.env`（不进 git）和 EAS 的 preview 环境变量里。注意：App key 会被打包进 App，只能挡住随手的滥用，正式上线前要换成用户登录。

| ⑤ 版面导演（30 页，Claude Haiku 5.5，实测每页约 $0.0002） | — | 约 $0.01 |

## 还没做的

- **用户登录**：现在靠 App key 防滥用，正式上线前要换成每个用户自己的身份和用量上限。
- **更便宜的转写**：Soniox（约 $0.0017/分钟）和 Gemini Flash-Lite（约 $0.0009/分钟）有账号或额度后再测，过关就换。
- **用真实录音再测一轮**：现在的 24 段是构造的，需要换成真实的日记录音，尤其是长段落和中英混说。
- **隐私**：DeepSeek 模型在 Together 的美国机房跑，Claude 在 Anthropic；上线前要写清楚文字会发到哪里、保留多久。

## 怎么跑

```bash
cd agent
node eval/run.mjs                 # 全部模型
REPEAT=2 node eval/run.mjs deepseek haiku   # 只跑名字里含这些词的模型，每段两遍
node director.mjs                 # 用 App 里的示例日子跑一次版面导演
```

Together 的 key 从 `Many Minds/engine/.env.local` 读，Claude 的 key 用环境变量里的 `ANTHROPIC_API_KEY`；两者都不会被打印或写进文件。
